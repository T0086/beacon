# beacon — 桌面常驻条（课程 / 硬件 / 天气）

## 它是什么

一个 PowerShell + WPF 的单文件桌面常驻条，独立进程，开机自启。

和 `desktop-orb` 不是同一个东西，别混：

| | desktop-orb（DSH 插件） | beacon（这个） |
|---|---|---|
| 技术 | Electron + DSH 插件 | PowerShell 5.1 + WPF |
| 能对话 | 是（进 DSH 会话） | 否 |
| 显示 | 费用查询 / 状态 / 诗词 | 时间 / 硬件 / 课程 / 天气 |
| 启动 | 随 DSH | 独立，计划任务开机自启 |
| 进程 | electron | powershell.exe |

## 启动与安装

```
安装.bat            →  自提权跑 install.ps1
                       ├ 复制文件到 app\
                       ├ 建计划任务 Beacon（RunLevel Highest，AtLogOn）
                       └ 立刻启动
启动 beacon.vbs      →  无黑框启动器（相对路径，可搬目录）
```

**为什么必须管理员**：读 CPU 温度要用内核驱动（LibreHardwareMonitor 内嵌 WinRing0）。非管理员跑起来温度一栏会是 `--`。

单实例靠 `Global\Beacon_SingleInstance` 互斥量守护，重复启动不会开出第二条。

## 外观

收起态 **470×76**，圆角 14，四块：

```
23:41
15          CPU 12%  48°C   GPU 9%    Course A      🔓 📌
周日        RAM 15.6/31.1G  6°C 阴    明天 09:00
```

左块三行：时间（小灰）→ 日期（大白）→ 周几（小灰）。日期是主角。
中间是硬件与天气，右边是「下一件事」。布局固定列宽，数字怎么变都不推动别的块。

展开态 **380×560**，顶部「日程 / 月历」切换，下方备忘输入框。

## 硬件指标

| 指标 | 来源 | 刷新 |
|---|---|---|
| CPU 占用 / 温度 | LibreHardwareMonitorLib 0.9.3 | 2 秒 |
| GPU 占用 / 温度 | 同上，独显核显都认 | 2 秒 |
| RAM | 同上 + 系统总量 | 2 秒 |
| 天气 | Open-Meteo（免费、无 key、按经纬度） | 20 分钟 |

LHM 7 个 DLL 放在 `app\lib\`，随包分发，**不需要装驱动、不依赖 AIDA64**。

AIDA64 注册表读法（`HKCU\Software\FinalWire\AIDA64\SensorValues`）还留着，只作兜底：LHM 拿不到温度时才去读，读不到显示 `--°C`。

温度阈值：≥70°C 橙、≥85°C 红。

监控哪块显卡在设置里选（自动 / 具体某块）。「自动」= 优先独显。

## 锁定与鼠标穿透

长条右侧两个图标：

| 图标 | 作用 |
|---|---|
| 🔓 / 🔒 | 锁定：整条变半透明、**点击直接穿透**到后面的窗口 |
| 📌 | 层级：贴顶 / 沉底 |

穿透的实现有坑：`WM_NCHITTEST` 返回 `HTTRANSPARENT` **只在同线程窗口之间有效**，跨进程（比如点浏览器标签）根本穿不过去。真正管用的是 `WS_EX_TRANSPARENT`（0x20）。

但那样小锁自己也点不动了，所以在小锁正上方停了一个 34×34 的**隐形窗口**（背景 `#01161920`，alpha 1/255，看不见但能被点），专门接「解锁」那一下。

## 永不抢焦点

主条带 `WS_EX_NOACTIVATE`（0x08000000）：点它不会成为前台窗口，打游戏时鼠标滑过、点到，游戏都不会丢焦点。

实测：窗口样式 `0x80008 → 0x8080008`，点击前后 `GetForegroundWindow` 句柄不变。

**没解决的**：光标停在条上时滚轮会被条吃掉。要彻底解决得做「全屏程序自动穿透」，还没做。

## 设置窗口（640×600，左侧导航）

一个项目一块，不做成一层层往下滚的长页。

| 分块 | 内容 |
|---|---|
| 显卡监控 | 自动 / 可选具体显卡 |
| 出现位置 | 固定到坐标 or 跟随上次；也可手动填 X/Y |
| 天气位置 | 经纬度；**留空即用谢菲尔德默认** |
| 日历订阅 | 粘贴 .ics 链接、已导入列表、逐条删除 |
| 关于 | 版本号、项目主页、数据本地留存说明 |

### 出现位置

`固定` 与 `跟随` 分开存，互不干扰：

- 固定：`PosPin=true` + `PosLeft/PosTop`，拖动**不再覆写**
- 跟随：读 `Left/Top`（每次退出时保存的当前位置）

坐标是 DIP（设备无关单位），不是物理像素。副屏 150% 缩放时按截图量会差 2/3，用「固定到当前位置」最省事。

### 天气位置

输入框默认空，占位「纬度 / 经度」在空的时候才显示。两个都留空点「应用」= 清掉自定义坐标、回到谢菲尔德。

## 备忘与月历

**不写日期** → 留在面板下方备忘区。
**写了日期** → 挂到课程列表里那天所有课程下面，橙色「截止 xxx」。

deadline 挂在**日期**上而不是课程 ID 上——课表来自只读的 `calendar.ics`，挂 ID 的话课表一更新就全对不上。

月历 7×6：课程按配色打点（最多 3 个）、橙色点是截止、今天红字、点日期出红圈并在下方展开当天日程。

## 日历订阅

设置里粘贴 `.ics` 链接（http / https / webcal）即可，支持 Google / Outlook / Apple / 学校教务。
存 `imported.json`，删除源立刻从界面消失。

**每天 22:00 自动重拉**所有导入源。本地 `schedule.json` 不在自动刷新范围（它是从课表生成的本机文件）。

## 发版

```powershell
powershell -File tools\release.ps1 -Version 1.0.4 -Notes "改了什么"
```

依次做：改版本号 → 补 BOM → 语法检查 → 同步 `app\` → 推 `app/beacon.ps1` → 打包 → 建 release → 传资产。

仓库 https://github.com/T0086/beacon ，资产是 `beacon-<版本>.zip`，结构固定：`app\` + `LICENSES\` + `install.ps1` + `README.md` + `安装.bat`。

## 重启的正确姿势

不要 `Stop-Process -Force`——托盘会留幽灵图标。

```powershell
Set-Content quit.flag '1'        # 2 秒内轮询到 → 释放托盘 → 退出
Start-Sleep 4
Start-ScheduledTask -TaskName Beacon
```

`quit.flag` 自己会被删掉。

## 已知限制

- 中文输入法下回车不提交备忘（IME 把回车当确认候选词），主入口是 `+`
- 窗口固定两态 470×76 / 380×560，不支持拉伸
- 面板从长条左侧展开，靠屏幕左缘会被推回来
- 多屏：位置校验是否落在真实屏幕内，否则回主屏右上角
- 锁定态下滚轮仍会被条吃掉（见上文）
- 设置窗口刚出现时，**第一次点击只等于给窗口聚焦**，要点两下

## PowerShell 5.1 的坑（都踩过）

1. `.ps1` 有中文必须 **UTF-8 with BOM**。编辑工具常把 BOM 抹掉，之后 PS 按 GBK 解码，中文变乱码并报假语法错。改完必须复查 BOM 再用 `Parser::ParseInput` 验一遍。
2. `WM_NCHITTEST` + `HTTRANSPARENT` 只对同线程窗口生效，跨进程穿透要用 `WS_EX_TRANSPARENT`。
3. `Get-Process` 没有 `CommandLine`，用 `Get-CimInstance Win32_Process`；过滤脚本名会匹配到执行查询的 shell 自己，要排掉 `$PID`。
4. WPF `Button` 改 `Background` 要自定义 Template，否则默认模板盖掉。
5. `ConvertFrom-Json` 会把日期串偷偷转成 DateTime，后续 `ParseExact` 会炸。
6. `{ }.GetNewClosure()` 会新建 SessionState，里面 `$script:` 变量解析不到，事件处理器改用 `sender.Tag`。
7. 窗口样式要在 `SourceInitialized` 之后改，句柄才有。
8. 自动化点击测试要用应用自己的 DIP 坐标，别按截图的物理像素量（150% 缩放差 2/3）。
9. `Add-Type` 的 user32 声明同一进程只能加载一次同名类，多段脚本要换类名。
