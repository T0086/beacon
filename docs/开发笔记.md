# beacon — 桌面悬浮课程表 + 备忘

## 名字的由来

工作区里原本已有一个 **`desktop-orb`**：11/11–11/14 做的 Electron 悬浮球，
能通过 DSH 会话对话（`chatMode: session`），带诗词。它作为 `@local/desktop-orb`
插件随 DSH 启动。

这个球改叫 **`beacon`**：

| | desktop-orb（旧） | beacon（新） |
|---|---|---|
| 技术 | Electron + DSH 插件 | PowerShell + WPF |
| 能对话 | 是（进 DSH 会话） | 否 |
| 显示 | 诗词 / 状态 | 课程表 / 备忘 / 硬件指标 |
| 启动 | 随 DSH | 独立，开机自启 |

## 启动

```
<old-launcher.vbs>
```

双击不弹黑框。已设为开机自启（Startup 里的 `beacon.lnk`）。

## 外观与实时指标

收起态是 **470×76 的钝边长方形**（圆角 14），四块内容：

```
11:16                              
15          CPU 12%  48°C   GPU 9%    Course A      🔓 📌
周日        RAM 15.6/31.1G  6°C 阴    明天 09:00
```

最左边日期块是**三行居中**的：时间（小灰）→ 日期（大白）→ 周几（小灰）。
按醒目度排优先级，日期是主角。

最右边那块是**「下一件事」**：自动挑出最近的课程或截止项。

- 按时间排序，课程和截止一起比
- 已经过去的今天课程会跳过
- 课程名取**前 2-3 个单词**（原文，不缩写），尾部 `and/to/of` 会去掉。
  例如 `Course A` → `Course A`，
  `Course B` → `Introduction to Data`。ToolTip 显示全名
- 截止项橙色字，前面有一个**颜色小球**表示紧迫度：

| 颜色 | 含义 |
|---|---|
| 🔴 红 | 今天到期或已过期 |
| 🟡 黄 | 3 天内 |
| 🟢 绿 | 3 天以上 |

**布局是固定列宽**（52 / 192 / 弹性 / 48），指标用等宽槽位，数字怎么变都不会推动其他块。

| 指标 | 来源 | 刷新 |
|---|---|---|
| CPU 占用 | `PerformanceCounter('Processor','% Processor Time')` | 2 秒 |
| CPU 温度 | AIDA64 注册表导出，`Value.TCPU` | 2 秒 |
| GPU 占用 | `nvidia-smi --query-gpu=utilization.gpu` | 2 秒 |
| RAM | `PerformanceCounter('Memory','Available MBytes')` + 总量缓存 | 2 秒 |
| 天气 | Open-Meteo（预设坐标，免费无 key） | 20 分钟 |

### CPU 温度需要 AIDA64 配合

这台机器的 ACPI 和 PDH 都不暴露 CPU 温度（`MSAcpi_ThermalZoneTemperature`
返回 Not supported）。温度走 AIDA64 的对外接口：

**AIDA64 → 文件 → 设置 → 硬件监控 → 外部应用程序 → 勾选「Enable writing sensor values to Registry」**

勾上之后 AIDA64 会把传感器值写到：

```
HKEY_CURRENT_USER\Software\FinalWire\AIDA64\SensorValues
```

键名是传感器 ID，CPU 温度是 `TCPU1`。beacon每 2 秒读一次，读不到就显示 `--°C`。
温度 ≥70°C 变橙、≥85°C 变红。

AIDA64 退出时会删掉这个注册表路径，那之后温度就回到 `--`。

## 锁定 / 层级 / 22:00 自动刷新

收起态长条右侧有两个小图标：

| 图标 | 作用 |
|---|---|
| 🔓 / 🔒（灰→橙） | **锁定**。锁上之后长条不响应点击和拖动，防止误触；再点一次解锁 |
| 📌（蓝=置顶 / 灰=最底） | **层级**。蓝色是置顶，灰色是沉到最底（会被其他窗口盖住） |

**每天 22:00 自动拉取** `imported.json` 里所有日历源并刷新。
本地课表 `schedule.json` 不在自动刷新范围内（它是从 `calendar.ics` 生成的本机文件）。

导入入口在「设置」齿轮里（和关闭 ✕ 同风格的小图标）。

## 导入日程（独立设置窗口）

面板右上角「设置」打开一个**独立弹窗**（不是面板里的一个视图）：

- 粘贴 `.ics` 链接（`http` / `https` / `webcal` 都行）
- 点「导入」，下载并解析
- 导入的日历列在「已导入的日历」里，每条带 ✕ 可以删掉

导入的事件会和课表**合并显示**——日程列表、月历视图都会带上。
数据存在 `imported.json`，删除某条源会立刻从界面消失。

**支持的**：Google / Outlook / Apple 日历导出的 "私人 iCal 地址"、学校系统给的 `.ics` 链接。
**不支持的**：需要登录才能看的网页、非 `.ics` 的日历页面、`.html` 文件。

## 备忘怎么分流

**不写日期** → 留在面板下方的「备忘」区。
**写了日期** → 挂到上面课程列表里**那天所有课程下面**，橙色底的一行「截止 xxx」。

点了日期的那条备忘**不会**再出现在备忘区，它只属于那一天。

课程列表里的截止行可以点击切换完成，完成后就不再显示（数据还在 `notes.json`）。

**取舍**：deadline 挂在**日期**上，不是挂在某节课的 ID 上。
因为课程数据来自只读的 `calendar.ics`，挂课程 ID 的话课表一更新就全对不上。
所以它显示在"那天的课程下面"，不精确到某一节。

## 月历视图

面板顶部「日程 / 月历」切换。月历是 7×6 网格：

- 每天下面有彩色小点 = 那天的课程（按课程配色，最多 3 个）
- 橙色小点 = 那天有备忘截止
- **今天**：红字
- **点击任意日期**：日期数字外出现**红色圆圈**，下方显示那天的完整日程（课程 + 截止项）

月历下半部分会跟着选中的日期变。没有安排的日子显示「这天没有安排」。
切换回「日程」再切回来，选中状态保留。

## 已知限制

- **中文输入法下回车不提交备忘**（IME 把回车当"确认候选词"）。主入口是 `+` 按钮。
- 窗口只有 420×76 / 380×560 两态，不支持拉伸。
- 面板从长条左侧展开，靠屏幕左缘会被推回来。
- 多屏：位置会校验是否落在某个真实屏幕内，否则回主屏右上角。

## PowerShell 5.1 踩过的坑

1. `Add-Type -AssemblyName` 要用 `System.Windows.Forms`，不是 `Windows.Forms`。
2. `@(cmd | ConvertFrom-Json)` 会把整个数组包成**一个**元素。
   先 `$parsed = ... | ConvertFrom-Json`，再 `@($parsed)`。
3. `ConvertFrom-Json` 会把 `"2026-11-16"` 悄悄转成 DateTime，后面 `ParseExact` 就炸。
4. `{ ... }.GetNewClosure()` 会新建 SessionState，里面 `$script:Notes` 解析不到（变 null）。
   事件处理器用 sender 的 `.Tag`，别用闭包变量。
5. OrderedDictionary 里存 `ArrayList`，读出来 `.Add()` 报 `Collection was of a fixed size`。
6. `.ps1` 里有中文，**必须存成 UTF-8 with BOM**。
7. `Get-Process` 没有 `CommandLine`，要用 `Get-CimInstance Win32_Process`；
   过滤条件里写了脚本名会匹配到正在执行的 shell 自身，要加 `$_.ProcessId -ne $PID`。
8. WPF `Button` 改 `Background` 要自定义 Template，否则默认模板盖掉（见 `TabBtn` 样式）。
9. `Get-NetAdapter` 在 wscript 拉起的 PowerShell 里可能没自动加载模块，
   要显式 `Import-Module NetAdapter`。
10. `New-ScheduledTaskTrigger` 没有 `-Delay` 参数，要先建再赋 `$trig.Delay`。
